# 砥礪 dili-stone

> 寶劍鋒從磨礪出。

**砥**是細磨刀石，**礪**是粗磨刀石。劍不會自己變鋒利，要一次次在石上磨。

這個專案就是那塊石頭：為國中生產生英文考卷，小考、段考、複習考，一張一張磨下去，學問才會鋒利。它本身不是武器，是讓人變利的工具。它也和 [湛盧 zhanlu](https://github.com/ITE-Richard/zhanlu)（名劍）湊成一對：一個是劍，一個是磨劍的石。

## 做什麼

依指定範圍產生台灣國中英文**筆試**考卷，輸出 Word。

- **使用者**：家長幫孩子出題、學校老師出段考題
- **範圍**：國一～國三任一冊的單課、多課（例如第 7～8 課）或全冊
- **考試類型**：小考、段考、複習考，每次產出一整張考卷
- **輸出**：Word（`.docx`）試題卷，以及附解析的答案卷；卷頭（校名、年級、班級座號、範圍、配分）可設定
- **不含**：聽力（聽力是另一張卷子）

## 設計方向

目前在需求與架構討論階段，由 Claude Code、Antigravity、Codex 透過 [Agora](https://github.com/ITE-Richard/agora) 討論後取得共識。

**教材資料**
- 國中英語審定本出版者為**佳音、康軒、南一**；一般說的「翰林版」由佳音出版（佳音翰林）。
- 每課以「單字＋文法句型」為核心，從公開來源整理（各校課程計畫、出版社公開資源、教育部酷英等）。
- 每筆資料記錄來源網址、版本學年度、完整程度與使用條件；資料不齊的課次標為「部分對應」。
- 日後若取得課本、補充教材（PDF／Word）或範本考卷，用同一套資料結構補入，精度跟著提升。
- 原始教材與範本考卷放在 `materials/`（不進 git）；`data/` 只存字詞、詞性、中文義、文法點等結構化資料，不存課文、例句或範本原題。
- 範本考卷只用來歸納卷型（大題、題數、配分），不當生成素材。
- Reading Success 等各校自選的補充讀本每年範圍不同，不納入。

**超範圍檢核**
- 分三層：本次考點／已教過的先備知識／需附註解的生字。
- **考點**只來自本次範圍：例如單字選擇題，選項與被考的字必須是範圍內單字。
- **先備知識**：課綱附錄的 1200 基本字可直接出現在題幹、短文與情境中，但不當考點；其餘 800 字必須附中文註解。
- 範圍外的生字可附中文註解；範圍外的句型或未教考點則退回重寫。
- 教材本身的分類（應用字彙／認識字彙／第二義）與出卷分層分開記錄。

**出題流程**

```
教材解析 → 人工確認 → 出卷藍圖 → Agora 分大題派工生成 → 另一個 AI 交叉審題 → 修題
        → 程式檢核（超範、配分、題數、重複） → 網頁閱卷（使用者） → 依意見修題 → 輸出 Word
```

| 指令 | 用途 |
| --- | --- |
| `dili make 藍圖 [--run ID]` | 一次出一份新考卷：分配考點、三個 AI 平行出題、交叉審題、修題、檢核（也可雙擊 `new-exam.bat`） |
| `dili plan 藍圖 --run ID` | 建立一次出卷，分配各大題考點 |
| `dili generate ID` | 經 Agora 派工出題，交付後自動檢核，有錯帶回重派 |
| `dili review ID`／`dili revise ID` | 另一個 AI 交叉審題／把審題意見交回出題者修改 |
| `dili review-ui [ID] [--reviewer 名稱]` | 開啟本機閱卷網頁：每題評難易度、寫意見，可暫時存檔、完成閱卷（也可雙擊 `review.bat`；不指定 ID 時用最近一次出卷） |
| `dili feedback ID` | 把完成的閱卷意見交回出題者修改 |
| `dili build ID` | 整卷檢核並輸出試題卷與答案解析卷 |

- 閱讀與克漏字採**原創短文**，以範圍內的單字與句型為主，可用先備字彙。
- 每份考卷產出兩本：**試題卷**，以及附**答案與解析**（說明為什麼是這個答案）的答案卷。
- 未經人工確認的題目標為「待審」；AI 交叉審題不代表保證正確。
- 閱卷時意見留空即視為核准；核准綁定題目內容，題目一改就回到待審。每位閱卷人分開記錄。
- 小考、段考、複習考共用同一套程式，只是出卷藍圖的參數不同。

## 第一階段試作

用**翰林八上（第三冊）段二範圍 Unit 2～5**（115 學年度教材），產出一份完整段考卷與解析答案卷（週考卷只當參考範本），驗收有沒有超範圍、題意不清、兩卷重複、總分錯誤與版面問題。

- 段考卷型參考範本：單題選擇 25 題×2、題組（克漏字／閱讀）20 題×1.5、文意字彙 10 題×1、依提示作答與翻譯 5 題×2，共 100 分。
- 題組要完整，包含需要圖片的題型（地圖、路線圖、筆記、圖表）；圖片由結構化描述以程式繪製，答案可從同一份描述驗證。
