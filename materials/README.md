# materials：原始教材與範本考卷

這個資料夾放原始檔（課本、習作、講義、範本考卷），**不進 git**（見 `.gitignore`），只有本說明會進版控。
整理後的結構化資料放在 `data/`，每筆會記錄來源檔名與頁碼。

```
materials/
  textbooks/<出版社>/<冊次>/   例：textbooks/jiayin/7a/L01-課本.pdf
  exams/                       例：exams/某國中-114-8a-第一次段考.pdf
```

- 出版社：`jiayin`（佳音翰林）、`kangxuan`（康軒）、`nani`（南一）
- 冊次：`7a` 七上、`7b` 七下、`8a` 八上、`8b` 八下、`9a` 九上、`9b` 九下
- 考卷檔名：`學校-學年度-冊次-考試類型`，答案卷加 `-答案`
- 檔名可用中文；格式不確定時先放進來，分析時再整理。
